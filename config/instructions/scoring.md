# Grille de notation (sur 100)

| Critère | Points |
|---|---|
| Compétences demandées présentes dans le profil | 35 |
| Type de contrat et niveau d'expérience compatibles | 20 |
| Localisation ou télétravail compatibles avec les préférences | 20 |
| Secteur ou type d'entreprise apprécié | 15 |
| Fraîcheur et clarté de l'offre | 10 |

# Règles
- Exiger plus de 3 ans d'expérience pour un profil junior : 40 maximum.
- Offre en anglais : aucune pénalité si le profil indique l'anglais.
- Mentionner dans red_flags : salaire absent, description vague, cabinet sans nom d'entreprise.
- excluded = true si un critère « exclure » de la veille s'applique.
